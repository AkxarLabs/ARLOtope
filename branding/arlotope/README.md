# ARLOtope

Arlo is the axolotl character. The identity keeps the Lab's ivory face, pink/lavender/teal gills,
small smile and quiet editorial typography.

- `arlotope-logo-concept.png`: transparent horizontal head-and-wordmark concept, 2172 × 724.
- `arlotope-head-concept.png`: standalone transparent head concept, 1254 × 1254.
- `generation-prompts.md`: generation instructions and reference sources.
- `preview.html`: self-contained preview on cream and dark backgrounds.
- `arlotope-logo-boxed-v2.png`: revised single-ink logo, with the head contained inside a rounded square.
- `boxed-v2.html`: self-contained preview of the more restrained direction.

The active identity is **ARLOtope**: uppercase ARLO, lowercase tope. Production raster assets live in
`dashboard/static/brand/` and `docs/assets/brand/`: `arlotope-wordmark.png` and `arlotope-mark.png`.
Both are transparent, single-ink images. Dark-mode CSS uses the same mark in light ink.
The earlier files above are retained concepts, not the current wordmark. These are raster assets,
not vector masters. The GitHub repository is `AkxarLabs/ARLOtope`; the command is `arlo` (`arlo.py`),
project records use `.arlotope/`, and environment variables use `ARLOTOPE_*`.

The original character reference is `output/playwright/visual-workflows/newt-day.png`.


The README and docs use small, editable SVG wordmarks in `docs/assets/brand/`.
`arlotope-wordmark.svg` uses dark ink; `arlotope-wordmark-dark.svg` uses light ink for GitHub's
dark theme. Both preserve the boxed axolotl and ARLOtope capitalization, with system serif text.
The dashboard retains its existing raster assets. The docs apply their own night-mode filter.
